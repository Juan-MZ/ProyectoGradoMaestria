# ADR-0022. Licencia dual: documento CC BY-NC-ND 4.0 y código Apache 2.0

- **Estado:** Aceptada
- **Fecha:** 2026-10-19 (retrospectiva)

## Contexto

El repositorio es público y contiene a la vez una obra académica y software.

## Decisión

La monografía y sus figuras se licencian con CC BY-NC-ND 4.0; el código, con
Apache 2.0. Las imágenes de terceros se conservan y se citan completas
(`TERCEROS.md`).

## Alternativas consideradas

- Una sola licencia: o restringe el código o desprotege la obra académica.

## Consecuencias

- Terceros pueden reutilizar el prototipo; la monografía no se modifica sin
  permiso.

## Respaldo

Políticas de propiedad intelectual de trabajos de grado; textos de las
licencias.
